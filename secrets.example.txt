# hush global secrets file
#
# Always loaded. Add more files with HUSH_SECRETS_FILES (see the README).
#
# One secret per line:   label: secret
#
#   - The label comes first and may contain letters, digits, - and _.
#   - After the colon: at least one space, then the secret exactly as it
#     is. Colons, =, # and [ inside a secret are fine; nothing is escaped.
#   - "redacted" gives a plain <REDACTED>. Any other label gives
#     <REDACTED-LABEL>, e.g. "email:" gives <REDACTED-EMAIL>.
#   - Lines starting with # are comments. Blank lines are ignored.
#
# Add secrets without printing them:
#   aws configure get aws_secret_access_key --profile NAME | hush add
#
# Examples:
#
# redacted: AKIAIOSFODNN7EXAMPLE
# redacted: wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
# email: john@example.com
# ip: 10.10.10.15
# aws-account-id: 123456789012
# password: pass=word:with#odd[chars
